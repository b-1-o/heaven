# HEAVEN

A premium developer-operations workspace built as a frontend engineering showcase.

## Focus

- Glass / fog visual system
- Dense but calm information architecture
- Command palette and keyboard-first navigation
- Dashboard metrics and analytics
- Project / task / deployment workflows
- Responsive mobile experience
- Loading, empty, success and error-ready states
- Accessible focus and interaction patterns
- GitHub Pages deployment

## Run

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```

## Design direction

HEAVEN intentionally avoids generic “AI dashboard” aesthetics. Surfaces are built from translucent layers, blurred atmospheric fields, fine borders, quiet typography and restrained motion.
